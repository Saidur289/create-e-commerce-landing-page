# ChicWove — E-commerce Landing Page

A responsive fashion e-commerce landing page built with HTML5, Tailwind CSS, GSAP 3 (ScrollTrigger), Lenis smooth scroll and Lucide icons, featuring blur-to-clear and spring (`back.out` / `elastic.out`) animations.

## Run

Open `index.html` in a browser — no build step needed.

## Screenshots

See the `screenshots/` folder (captured with [Puppeteer](https://pptr.dev/)).

```bash
npm i puppeteer
node check-animations.mjs index.html screenshots 1280
```
